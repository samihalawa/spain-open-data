## Reviewer walkthrough

Install the exact candidate marketplace and verify the declared server appears. Call `spain_open_data_demo` and inspect its dated historical marker. Call `spain_open_data_report` with the demo operation and `format: html`; it returns escaped portable text, with no file write or external assets. Exercise the domain operation `open_data_compare` only with an authorized official-source query and inspect dates, coverage, provenance and partial errors.
