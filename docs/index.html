03Primer uso

Empieza por una pregunta real.

Busca datasets sobre empleo y compara su publicador, formato, licencia declarada y fecha de actualización.
Límites de la herramienta
  • Un dataset en el catálogo no acredita descarga, calidad, actualidad ni permisos efectivos de redistribución.
  • La muestra tiene fecha de consulta y enlaces oficiales. No se han fabricado cifras ni actuaciones.
  • La disponibilidad de los sistemas oficiales puede variar; un fallo de origen nunca se presenta como cero resultados.
04Distribución

Un instrumento.
Sin otra plataforma que gestionar.

Plugin independiente con habilidades y MCP local para anfitriones de escritorio compatibles. No requiere cuenta adicional ni claves de API para consultar datos públicos.

/plugin install spain-open-data --marketplace samihalawa/spain-open-data
