¿Qué ocurre en ChatGPT o sin terminal?

El flujo utiliza únicamente navegación y archivos disponibles en el anfitrión. Este paquete no añade un servidor MCP alojado ni permisos nuevos.

¿Puedo probarlo sin conexión?

Sí. La orden demo reproduce la captura incluida y la etiqueta como ejemplo. No simula una consulta actual.

¿Puedo guardar o compartir el resultado?

Exporta Markdown, JSON o un HTML autónomo. Revisa los datos antes de compartir. El informe HTML no ejecuta scripts ni carga recursos externos.

¿Qué no hace?

No descarga automáticamente distribuciones externas ni ejecuta archivos. No garantiza licencias o descargas vigentes. La fecha del catálogo no equivale al periodo del dato.
